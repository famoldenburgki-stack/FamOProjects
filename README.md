# FamOProjects

Sammlung eigener, privat genutzter Programme.

## Projekte

### [arztrechnungen](arztrechnungen/)

Lokale Verwaltung von Arztrechnungen für einen beihilfeberechtigten, privat
versicherten Haushalt: Rechnungen werden per Texterkennung erfasst, an Beihilfe
und Krankenversicherung getrennt nachverfolgt, und eingehende Bescheide werden
automatisch den Einreichungen zugeordnet und geprüft.

Node.js, TypeScript, SQLite, React. Läuft ausschließlich auf dem eigenen Rechner.
Einzelheiten in [arztrechnungen/README.md](arztrechnungen/README.md).

### [DocKit](DocKit/)

Baukasten für Schriftgut: Textbausteine, Formularfelder und Vorlagen, aufgerufen per
systemweiter Tastenkombination und eingefügt an der Cursorstelle des zuvor aktiven Programms.

Reine Windows-Bordmittel (PowerShell 5.1 + WinForms), keine Installation, keine Fremdbibliothek,
läuft portabel vom USB-Stick. Einzelheiten, Download- und Starthinweise in
[DocKit/README.md](DocKit/README.md).
